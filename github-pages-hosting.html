Interne Notiz · Hosting-Empfehlung

GitHub Pages für die Lehrer-Infoseite

Wir wollen eine einfache, öffentliche Infoseite mit Link zum Schul-Moodle veröffentlichen — ohne Schülerdaten, ohne Namen, ohne Noten, keine kommerzielle Nutzung. Diese Notiz begründet die Empfehlung für GitHub Pages und hält fest, worauf zu achten ist.

Überblick / Ziel

Was die Seite sein soll — und was nicht

Eine einfache, öffentliche Infoseite mit einem sichtbaren Link zum Schul-Moodle, über den sich Schüler ganz normal einloggen können, um Tests zu machen. Es geht nicht ums Geldverdienen, sondern um eine reine Informationsseite.

Warum GitHub Pages

Kostenlos, dauerhaft, werbefrei

  • Kostenlos und dauerhaft — kein „1 Jahr gratis, dann Kosten"-Modell.
  • Kein Werbebanner auf der Seite.
  • Kann später mit einer eigenen Domain verbunden werden.

Grenzen von GitHub Pages

Was zu beachten ist

Technische Grenzen
Für unsere Zwecke unkritisch
  • Max. 1 GB Seitengröße, 100 GB Bandbreite/Monat (Soft Limit)
  • Nicht gedacht für kommerzielle Nutzung/Zahlungsabwicklung — für uns irrelevant
Wichtigster Punkt
Das Repository ist im kostenlosen Plan öffentlich

Jeder kann den kompletten Quellcode und die gesamte Versionshistorie einsehen. Auch gelöschte Commits bleiben in der Historie technisch auffindbar.

  • Daher: niemals Namen, Noten, E-Mail-Adressen oder andere personenbezogene Schülerdaten in den Code oder ins Repo einfügen — auch nicht in alten Commits.

Rechtliche Punkte

Vor dem Livegang zu klären

  • Impressum ist auch bei einer simplen Info-Seite ohne Kommerz Pflicht (TMG/DDG).
  • Vor dem Livegang: Rücksprache mit dem/der Datenschutzbeauftragten der Schule, ob eine extern gehostete Seite mit Link zum internen Moodle so in Ordnung ist — Vorgaben können je nach Bundesland/Schule abweichen.

Nächste Schritte für die Kollegin

So geht's los

  1. GitHub-Account erstellen auf github.com — kostenloser Plan reicht.
  2. E-Mail bestätigen über die Bestätigungs-Mail von GitHub.
  3. Zwei-Faktor-Authentifizierung aktivieren.
  4. Als Collaborator hinzufügen lassen — nicht eigenes Pages-Repo aufsetzen, damit es nur eine gemeinsame Seite gibt.
